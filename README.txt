CARTA DE CUMPLEAÑOS

1. Abre index.html en tu navegador.
2. La carpeta fotos contiene las 6 imágenes.
3. Puedes cambiar los textos de cada recuerdo en script.js.
4. Puedes cambiar el texto principal directamente en index.html.
5. Para subirla a un hosting, sube index.html, style.css, script.js y la carpeta fotos.

La página no necesita servidor: funciona como sitio estático.
